## 本机 HTTP 实测

用 Uvicorn 监听本机回环地址，HTTP 客户端使用四份独立凭证操作同一临时 SQLite 文件。建房后三人加入，逐人提交时用另一成员凭证核对 1/4 到 4/4。四人提交后，共同窗为北京时间 13:30–17:00，共同交通为 `metro`、`walk`，最小预算为 8000 分。将一人预算改为 7000 分后，人数仍为 4/4，汇总更新为 7000 分。

结束第一个 Uvicorn 进程并确认端口关闭，再启动不同进程打开同一文件。重放建房和三次加入，均返回原身份。四份原凭证仍可读取原房间、4/4 进度及更新后的汇总。
