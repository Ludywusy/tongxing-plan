| 条目 | 已确认口径与处理 | 当前证据 / 后续 |
| --- | --- | --- |
| A-05 时间 | 按房间 Asia/Shanghai 展示；13:00+08:00 与 05:00Z 都显示 13:00。选择日期与时间也按房间时区编码，不调用设备 toLocal。 | 单元及界面/HTTP 回归通过；C 待在非上海时区真机复验。 |
| W2-01 交通 | 唯一码表 metro、bus、taxi、walk、bicycle；bike 为旧别名，大小写不自动猜测。 | 表见 schemas/transport-codes.json；Flutter、HTTP 校验、历史汇总与 B 比较路径已覆盖；D 导出须对照同表回签。 |
| D-01 问卷 | “都行”仅在正式题干明确接受全部列出方式时可导出全选；“无”、空答依题意区分，含糊保留待确认。 | D 负责对照正式题干；本次不代填问卷，不推断缺失答案。 |
| 空交通 / 禁忌 | 空交通提示补填，服务返回 422；禁忌 [] 必须明确确认无禁忌。 | App 无默认全选，必须主动选交通或勾选无禁忌。 |
| 金额 | 个人预算含往返交通，以整数分传输，80 元 = 8000 分，不按组自动平摊。 | 小数输入按字符串精确换算，最多两位。 |
| 错误原因 | 时间冲突的 actual、threshold 可缺省；保留规则原因。 | 首批房间接口处理结构化字段错误；候选 HTTP 尚未接入，不能宣称候选 DTO 已联验。 |
| 汇总 | 共同窗、交通交集、最低预算只用于快照展示，不能取代四人原始偏好。 | 界面不把汇总回填个人表单；四份原始数据仍由服务保存。 |
| 版本与候选 | 候选不可变，状态维护递增计划版本；指纹由检测器产生。旧确认按原版本留存，变更记操作者、时间、preview_id 和基线版本，过期拒绝。 | 离线原型保存确认和批准历史，过期回归通过；联机候选/确认/变更接口后续接入。 |
| 评分范围 | 四机当前只验建房、加入、本人偏好和快照四接口；B 的第二周独立规划基线仍为硬约束过滤后软偏好排序。 | 本次不删除评分要求，也不把离线兴趣匹配标签当作规划评分实现。 |

对当前接口的 401/403/404/409/422 使用服务端结构化错误，不把重试失败当成功。建房/加入的网络不确定结果保留原请求和幂等键。详见 [Android 交付](week2-android.md)。
