## 四机最小验收

1. 让四台 Android 手机连接可访问同一 FastAPI 实例的网络。在手机 1 建房，记录本次房间和验收构建号。
2. 手机 2–4 输入同一个邀请码加入。各机核对自身成员身份和共同房间，四个成员 ID 各异。
3. 四台手机分别填写并提交各自的偏好。每次提交后在另一台手机读取快照，核对进度变化和成员提交标记。
4. 四台都读取最终快照，核对相同房间标识、四位成员、4/4 提交进度和相同汇总。记录各机型号、Android 版本、APK 及服务提交号、操作时间和结果。

最小验收覆盖建房、加入、提交和快照。后续联调选候选和同版本确认，校验旧版本返回冲突并提示刷新，再接变更预览及确认。首周的固定降雨样例继续用于 Android 和 Python 的回归对照。

当前待登记 B/C 接口回签、实际联调地址、四台真机和对应 APK。A、C、D 将实测结果填入[四机记录](week2-four-device-test.md)。D/B 补 POI 数据及规划样例。
