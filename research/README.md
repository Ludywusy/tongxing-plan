# 数据说明

- **可以入库：** 调研汇总、去除识别信息的匿名摘要、合成样例。
- **受限保管：** 问卷逐行答卷、原始导出、撤回码和个人信息；仅在团队受限资料区保存，不在公开仓库提供访问链接。
- **演示数据：** 注明来源、更新时间和模拟标记，不能把合成数据当作真实调查结果或实时信息。
- **字段约定：** 成员、候选和行程节点使用固定匿名 ID；金额以整数分保存，时间采用带时区的 ISO 8601 格式。

输入格式放在 `schemas/`，固定合成样例放在 `fixtures/`。`.gitignore` 已排除逐行答卷、原始导出与受限资料目录；提交前仍需检查文件内容。
