# 调研、竞品与预算 · D

公开仓库只保存汇总、匿名案例摘要、字段说明与合成预算样例。逐行答卷、原始导出、撤回码和识别信息放在团队受限资料区，不上传本仓库；也不在公开文档里暴露受限共享链接。

## 待交付

- `survey-form.md`：问卷、说明、跳转、正式入口与版本。
- `survey-analysis.md`：实际回收、有效份数、独立事件数、去重、缺失、排除口径和局限。
- `needs.md`：需求 ID、频次及分母/匿名案例编号、验收动作。
- `typical-constraints.md`：匿名语义、字段、单位、硬软属性与异常样例。
- `competitors.md`：地图、行程、群投票各一项实测，附日期、版本、复现步骤和匿名证据。
- `budget-model.md`、`budget-example.csv`：往返、门票、餐饮、共享支出和预留，分摊、舍入、来源与模拟标记。

## 数据口径

原项目计划为第一周访谈 8–10 组；队内第一周采用匿名问卷替代，目标 30 份有效答卷、至少 8 个独立真实出行或取消事件。分别统计答卷数与事件数，不能把目标数写成实际成果。

逐行清洗表 `survey-responses.csv` 虽在任务书列为交付，但只在受限位置保管。仓库仅记录字段说明与汇总；相关路径已经加入 `.gitignore`。

预算使用整数分，逐人合计应等于团队总额。参考合成例：每人固定 60 元，共享交通 80 元四人均摊，每人 80 元；共享交通 84 元时每人 81 元，预算上限 80 元者超 1 元。
