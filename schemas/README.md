# 数据契约 · C

目标文件：`trip-input.schema.json`，待提交；周三由 A/B/C 对齐 v0.1，D 复核预算语义。

至少约定：字段、类型、单位、必填项、缺失/空值策略和模拟数据标记。

- 成员：匿名 ID、带时区 ISO 8601 可用时间窗、预算上限（整数分）、允许交通、兴趣、明确禁忌。
- 候选：固定 ID、出发至返程时间、交通段、逐人成本、节点 ID 与地点标签。
- 事实与事件：来源、更新时间、模拟标记；降雨时间窗。
- 状态与变更：计划版本、可行状态、确认记录、受影响节点、保留节点与替代方案。

跨字段规则需说明：起止顺序、成员覆盖、ID 引用一致、金额合计、多时间窗与逐人预算。JSON Schema 不能独立表达的规则交由业务校验，不宣称仅凭结构验证即可保证行程可行。
